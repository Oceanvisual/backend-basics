# Backend Basics

Учебный проект для знакомства со структурой Python-проекта.

## Требования

Python 3.12

## Установка

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Проверка кода

```bash
ruff check .
ruff format .
```
